# Tic Tac Toe game

A simple Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features

- Two-player gameplay
- Interactive game board
- Reset game option

## Built With

- HTML
- CSS
- JavaScript

## How to Play

1. Player X starts the game.
2. Players take turns placing X and O.
3. The first player to get three in a row wins.
